# Contributing

Capital in Code is Dillon Nagar's personal project portfolio. Suggestions and corrections are welcome, but each project should stay focused, reproducible, and easy to understand.

## Adding a Project

1. Copy `templates/project-template/` into `projects/`.
2. Give the project the next unused code and a short lowercase name, such as `cic-002-market-question`.
3. Complete the project README before writing the analysis code.
4. Keep source code in `src/`, downloaded data in `data/raw/`, generated results in `results/`, charts in `charts/`, and written analysis in `analysis/`.
5. Add the project to the index in the main `README.md`.

## Naming Rules

- Use sequential codes: `CIC-001`, `CIC-002`, `CIC-003`, and so on.
- Use folder names in the form `cic-###-short-title`.
- Do not reuse a code, even if a project is retired.
- Use clear file names with lowercase words separated by hyphens or underscores.

Do not commit private information, secret keys, large downloaded datasets, or generated chart files. Explain assumptions, cite data sources, and write for readers who may be new to coding or investing.
