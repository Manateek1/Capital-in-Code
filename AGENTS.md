# Capital in Code — Codex Project Instructions

## Required Project Memory

- At the start of every task in this repository, read `PROJECT_CONTEXT.md` in full before planning, answering project questions, or changing files.
- Treat `PROJECT_CONTEXT.md` as the project's living memory. Use it together with the current repository state; the user's latest explicit instruction always takes precedence.
- Before finishing a task, update `PROJECT_CONTEXT.md` when the conversation or work establishes durable information such as a decision, goal, audience, product direction, scope change, naming convention, constraint, milestone, or meaningful status change.
- Do not update the context file for transient debugging details, guesses, or routine implementation steps that do not change the durable project picture.
- Preserve useful history with dated notes when a newer decision supersedes older context. Resolve contradictions explicitly instead of silently deleting important background.
- Never record secrets, credentials, access tokens, or unnecessarily sensitive personal information in the context file.
- When a task changes `PROJECT_CONTEXT.md`, mention that update in the final handoff.
