# Branding Direction

Capital in Code should look like a careful technical portfolio rather than a startup, fund, or financial product.

The visual direction is:

- Minimalist and primarily black and white
- Geometric, with a circle-based visual language
- Technical and financial without looking busy
- Clean, restrained, and credible
- Free of text inside the primary logo mark

The identity should work well on charts, project pages, repository graphics, and a future website.

## Primary mark

The primary mark is an abstract navy orbit with a rising signal path. It uses no
letters or numbers and is intended to suggest careful, upward-looking market
research without presenting itself as a financial product. The transparent
source asset is `capital-in-code-mark.png`; the unedited generated source is
kept as `capital-in-code-mark-source.png`.
