# Branding Direction

Capital in Code should look like a careful technical portfolio rather than a startup, fund, or financial product.

The visual direction is:

- Minimalist and primarily black and white
- Geometric, with a circle-based visual language
- Technical and financial without looking busy
- Clean, restrained, and credible
- Free of text inside the primary logo mark

The identity should work well on charts, project pages, repository graphics, and a future website. A primary logo has not been created yet.
