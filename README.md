# Capital in Code

Capital in Code is Dillon Nagar's public portfolio of coding and investing experiments. Each project explores a market or investing question using code, financial data, models, charts, and a short written analysis.

This repository is a portfolio, not a startup, fund, nonprofit, or formal academic journal.

## Why I Created It

Dillon Nagar created Capital in Code to bring together his interests in investing, coding, statistics, and financial modeling. The goal is to ask clear questions, test them carefully, and explain the results in plain language.

## What Each Project Includes

Each project is designed to include:

- A focused research question and a testable hypothesis
- The code used to clean data, run the experiment, and calculate results
- Notes about the data source and method
- Charts that make the findings easier to understand
- A short written analysis of the results and limitations
- Instructions for reproducing the work

## Project Numbering

`CIC` stands for **Capital in Code**. Projects receive a permanent three-digit code in the order they are added: `CIC-001`, `CIC-002`, `CIC-003`, and so on.
